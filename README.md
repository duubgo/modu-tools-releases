# 모두의 도구 Windows 베타 설치 파일

MODU 지인 베타 테스트용 Windows(x64) 설치 파일입니다. 설치·사용 안내는 https://philosophia-beryl.vercel.app/tools 를 보세요.

- **베타·미검증**: 설치·실행 검증을 마치기 전의 시험 배포입니다.
- **미서명**: 코드 서명이 없어 Windows SmartScreen 경고가 나올 수 있습니다. 보안 기능을 끄지 말고, 아래 SHA-256 을 확인한 뒤 설치하세요.
- **회원 로그인 필요**: 프로그램을 실행하면 MODU(모두의 섬) 회원 로그인을 요구합니다.
- **라이선스**: 각 프로그램은 ArtCraft 팀의 원본(MIT OR Apache-2.0) 기반이며, 설치 폴더 `docs\` 에 제3자 라이선스 고지(THIRD-PARTY-NOTICES.txt)가 들어 있습니다. 설치 프로그램은 WiX Toolset 5.0.2(MS-RL)로 만들었습니다.
- 모두의프레젠테이션·모두의영상·모두의영상효과는 코덱 권리 확인 중이라 이번 베타에서 제외했습니다.
